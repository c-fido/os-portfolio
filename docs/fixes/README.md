# Portfolio fixes

One file per surface a recruiter actually hits. Do them in this order — the first four are the ones that cost callbacks.

| Order | Surface | File |
|------:|---------|------|
| 1 | Boot screen | [boot-screen.md](./boot-screen.md) |
| 2 | Desktop | [desktop.md](./desktop.md) |
| 3 | About.txt | [about.md](./about.md) |
| 4 | Resume.pdf | [resume.md](./resume.md) |
| 5 | Projects | [projects.md](./projects.md) |
| 6 | Inbox | [inbox.md](./inbox.md) |
| 7 | GitHub (linked from the site) | [github.md](./github.md) |

Content for About, Projects, skills, and resume bullets lives in `src/data/portfolio.js`. The PDF at `public/resume.pdf` is what the Resume app actually shows — keep those two in sync.

Done when a recruiter can open [gfedolfi.dev](https://gfedolfi.dev), see Resume + Projects in under two seconds, and retell Remindr and the intern in one breath.
